# 🏙️ SMART CITY AI
### Intelligent City Management System

SMART CITY AI is an intelligent city management dashboard designed to monitor important city activities using a modern interface.

## 🚀 Features
- City Overview Dashboard
- Traffic Density Monitoring
- Air Quality Monitoring
- Active Alerts Management
- Emergency Management Center
- AI Prediction Engine
- City Reports
- City Zones Monitoring

## 🛠️ Technologies Used
- Python
- Matplotlib
- Data Visualization
- GUI Development

## 📊 Dashboard
The dashboard displays traffic density, air quality index, active alerts, and city zones.

**Note:** Dashboard values are demonstration data.

## 🎯 Project Objective
To create a smart city management system that helps visualize and monitor urban activities through a single dashboard.
